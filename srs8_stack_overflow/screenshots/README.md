# Скриншоты результатов Wokwi

После реальных запусков здесь появятся:
- `crash_result.png` — Serial Monitor эксперимента с бесконечной рекурсией.
- `safe_result.png` — конец итерационного эксперимента (`10000`, `SAFE FINISH`).
- `memory_hog_result.png` — наиболее показательный запуск Memory Hog (уровень указать в REPORT.md).

Реальные запуски проведены 13.11.2026, и все три PNG загружены в этот каталог. Для Memory Hog выбран запуск с level 3. Изображения фиксируют реально наблюдавшееся поведение, заглушки не используются.
