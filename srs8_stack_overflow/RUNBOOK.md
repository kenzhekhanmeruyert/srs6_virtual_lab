# Как выполнить эксперименты в Wokwi

## Сначала — Crash
1. Открыть https://wokwi.com/projects/new/arduino-uno.
2. Перейти к `sketch.ino` и вставить код из [code/crash.ino](code/crash.ino). Arduino Uno уже выбрана.
3. Запустить симуляцию. Скорость `Serial.begin(115200)` задаётся кодом.
4. Зафиксировать **последнее корректно напечатанное число**, затем описать конкретный симптом: прекращение вывода, зависание, перезапуск с новым START, искажение либо отсутствие заметной ошибки.
5. Сделать скриншот Serial Monitor `screenshots/crash_result.png`, сохранить проект и прислать ссылку.
6. Не переносить аварийный код на реальное устройство.

## Затем — Safe
1. Создать отдельный проект Arduino Uno.
2. Вставить [code/safe.ino](code/safe.ino).
3. Запустить; отметить, появилось ли `10000` и `SAFE FINISH`.
4. Сделать `screenshots/safe_result.png`, сохранить ссылку Wokwi.

## Наконец — Memory Hog
1. Создать третий проект Arduino Uno с [code/memory_hog.ino](code/memory_hog.ino).
2. **До первого запуска** изменить вызов `memoryHog(4);` на `memoryHog(0);`.
3. Запустить; записать видимые строки, наличие FINISH, ошибки или перезапуски.
4. Полностью остановить симуляцию, заменить аргумент на 1, перезапустить. Повторить с 2, 3 и 4.
5. Сохранить **все пять результатов** в REPORT.md. Сделать самый показательный скриншот `screenshots/memory_hog_result.png`.
6. В отчёте указать, с каким значением level связан скриншот. Не пытаться выдавать ожидаемые результаты за фактические.

## В завершение
Передать реальные скриншоты и URL проектов для коммита в GitHub. Заполнить ФИО, группу, ссылки и весь столбец «Факт» в [REPORT.md](REPORT.md), обновить раздел «Использование ИИ» после личной проверки.
